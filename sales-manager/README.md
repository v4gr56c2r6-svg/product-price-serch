# 絶叫焼き Sales Manager

PC・スマートフォン両対応の売上日報管理Webアプリです。HTML・CSS・JavaScriptとブラウザ標準のWeb Crypto APIだけで動作し、外部ライブラリ、外部API、解析タグ、外部フォントは使いません。

## 初版仕様

- 営業日ごとに日報を1件保存し、同じ日付の再保存で更新
- 入力項目：営業日、売上、客数、商品別販売数、天気、最高気温、混雑、品切れ商品、廃棄、特記事項
- 客単価は「売上 ÷ 客数」で自動計算
- アイス・箱入りの合計数は商品別販売数から自動集計し、二重入力を防止
- 日別の売上グラフ、月間の売上・客数・営業日数・客単価を集計
- 月次CSV出力、商品マスターと全日報の暗号化JSONバックアップ・読み込み
- 商品マスターと日報はAES-GCMで暗号化してブラウザに保存。パスワードは保存・送信しない
- 初回に12文字以上の専用パスワードを設定。解除中はヘッダーの「ロック」で画面を閉じる
- サーバー、クラウドDB、他端末への自動同期はなし

## 商品マスター

商品名と価格はアプリの「商品・価格一覧」画面から手入力してください。初期状態では商品データを含みません。商品マスターは日報と一緒に暗号化され、利用中のブラウザ内に保存されます。日報には販売時点の商品名・価格を記録するため、後で価格を変更しても過去の記録は変わりません。

以前の試作版で同じブラウザに保存された日報や商品マスターがある場合は、初回のパスワード設定時に暗号化して引き継ぎ、旧形式の保存データを削除します。

## 起動方法

Web Crypto APIを使うため、HTTPSまたはlocalhostで開いてください。`file://` から直接開く方法には対応しません。GitHub Pagesでは、このフォルダの中身を `/sales-manager/` に配置できます。

## 機密情報と公開前の確認

商品名・価格・日報データはアプリのHTML・JavaScriptには含まれず、AES-GCMで暗号化してブラウザ内へ保存します。鍵は入力したパスワードからPBKDF2-HMAC-SHA256（600,000回）で導出し、パスワード自体は保存・送信しません。長く推測されにくい専用パスワードを使ってください。パスワードを忘れるとデータを復元できません。暗号化JSONバックアップの読み込みにも同じパスワードが必要です。

暗号化は端末の侵害や、アプリが解除中のデータまでは守りません。信頼できる端末で使い、離席時はアプリをロックしてください。CSVはクリックすると平文でダウンロードされます。ブラウザデータの消去や端末故障に備え、暗号化JSONバックアップとCSVは会社承認済みの保管先に保存してください。

この初版は一端末・一ブラウザでの試作です。PCとスマートフォンで同じ商品マスター・日報を共有するには、会社承認済みの認証付きデータ保存先とアクセス権限設計が必要です。
